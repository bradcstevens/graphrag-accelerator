# Instructions

1. Create a dataset to use with GraphRAG. You may provide your own data or use the `web-crawler.py` script to download a small set of text data from a URL provided for demonstration purposes.

```shell
> python web-crawler.py
```

2. Follow instructions in the `graphrag-setup.ipynb` notebook to explore the GraphRAG API, by building an index of the data in `testdata` and executing queries.
